# valerie

a multipurpose discord bot with social commands, an economy, a shop, casino-style games and utilities. built in python, closed source. this repo is documentation only.

`beta v5.2`

---

## try it

valerie is not publicly invitable yet. public testing happens in the support server:

**[join the server](https://discord.gg/mjDGP8Bstu)**

found a bug or lost data? open a ticket in the tickets channel. have an idea? drop it in suggestions.

---

## what she does

| category | what's in it |
|---|---|
| fun | 8ball, jokes, facts, rate commands, emoji combos |
| media | gifs, animals, memes, nightcore, image to gif, captioning |
| social | 20 interaction actions: hug, pat, slap, wave and more |
| economy | profile, daily, work, mine, fish, crime, rob, leaderboard |
| shop | shop, buy, use, inventory |
| games | slots, roulette, blackjack, baccarat, minesweeper, towers, coinflip, rps, trivia |
| utility | ping, avatar, userinfo, serverinfo, inrole, help |

66 public commands in total. run `/help` in the bot for the live list.

---

## titles

titles can't be bought. you earn them through activity in the community, partnering with the server, and other things that stay unspoiled. they appear on your profile.

## status

valerie is in beta, built by one person with no budget. that means:

- uptime varies
- data saving has been unreliable, and data loss has happened
- things change fast

the full history is in [`changelog.md`](changelog.md).
