# changelog

everything valerie has gone through, newest first. all dates are 2026. versions are only listed where they were announced.

> valerie is a solo, zero-budget project. updates land when they land, uptime varies, and data loss has happened. see [known issues](#known-issues) at the bottom.

---

## oct 3: stability warning

- a big data corruption happened. it is *mostly* fixed.
- if you lost data or hit bugs, report it directly to the owner.
- more updates may follow depending on stability.

---

## v5.2: oct 1

- valerie's internal structure was changed. bugs are possible, report them in the main server or dm the owner.
- profile: fixed a bug that displayed items and titles incorrectly.
- announcements can now be posted by valerie herself instead of by hand.

---

## minor update: oct 1

**added**
- `/combos`: search for emoji combos from emojicombos.com.

**improved**
- `/help`: now lists every command and shows a total count.
- `/trivia`: you can now pick the category instead of getting random questions.

---

## v5: sept 30

**new**
- image to gif conversion (`/togif`).
- gif and image captioning (`/caption`).

**worked on**
- improved the robbing system.
- fixed cooldowns.
- improved the shop system.
- improved the profile system.
- usage system: items are no longer consumed automatically.
- fixed interaction commands pulling gifs from the wrong categories.

**hosting**
- earlier versions ran through VS Code on the developer's laptop, which ate too many resources. valerie was moved to a different hosting setup for better uptime.

**planned at the time**
- data saving.
- more minigames.
- video rendering (undecided).

---

## v4.5: sept 30

announcement made while this was the current version.

- valerie does not save data. version 2.0 had data saving but it was unstable, so different storage methods are being tested. expect data loss every time the bot goes offline.
- the bot has a $0 budget. anything spent comes from the developer's own pocket, so delays are expected.
- next update planned: revamped item system, revamped shop system, revamped profile, image captioning, image to gif conversion. most of this shipped in v5.

---

## known issues

- **data persistence:** saving data has been an ongoing problem. data loss happened on sept 30 and again with the oct 3 corruption. treat balances and inventories as not guaranteed.
- **uptime:** hosted on a budget of nothing, so downtime happens.
- **bugs:** report them in a ticket in the server's tickets channel.
